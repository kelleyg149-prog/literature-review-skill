# 资源与环境学科中期报告常见问题清单

## 选题层面
- 选题过大（如"中国水污染治理研究"），难以在硕士阶段完成
- 缺乏明确的环境/资源问题导向，选题过于理论化
- 技术路线过于理想化，实验室条件无法支撑
- 与导师研究方向或课题组积累偏离较大

## 文献层面
- 文献陈旧，缺少近3年核心期刊文献
- 只罗列不评述，缺乏对研究方法的对比分析
- 遗漏该领域经典文献或最新综述
- 未涉及相关国家标准或行业规范
- 对国内外研究差异缺乏分析

## 实验/调查层面
- 实验设计缺少对照组或重复实验
- 采样方案不合理（点位不足、频次不够、代表性差）
- 材料表征不充分，无法支撑后续机理分析
- 数据分析方法单一，缺少统计分析或误差分析
- 质控措施缺失或描述不清
- 无阶段性成果展示

## 写作层面
- 章节之间缺乏逻辑衔接
- 文献综述与研究内容脱节
- 图表缺少单位、误差棒或统计标注
- 环境数据未标注检测方法和检测限
- 格式不统一，引用混乱
