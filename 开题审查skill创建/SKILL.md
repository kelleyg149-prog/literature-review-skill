# 资源与环境学科硕士生中期报告审查技能

## 审查流程

1. 接收用户提交的中期报告内容（全文或关键章节）。
2. 识别学生所属具体方向（环境科学/环境工程/生态学/资源利用等），调整审查侧重点。
3. 按照 `references/review-criteria.md` 中的六大维度逐项审查。
4. 对照 `references/common-issues.md` 检查是否存在该学科常见问题。
5. 按照 `assets/review-template.md` 的格式输出结构化审查意见。
6. 参考 `examples/sample-review.md` 确保评审语气和深度符合标准。

## 学科方向识别与侧重

| 方向 | 审查侧重 |
|---|---|
| 环境科学 | 机理分析深度、环境行为表征、源解析方法 |
| 环境工程 | 工艺可行性、去除率/处理效率、工程参数 |
| 生态学 | 样地设计合理性、物种/群落数据完整性、统计方法 |
| 资源利用 | 资源化路径可行性、经济性分析、全生命周期评价 |
| 土壤/水修复 | 修复材料表征、模拟实验设计、实际场地适用性 |

## 审查维度概览

| 维度 | 权重 | 核心关注点 |
|---|---|---|
| 选题合理性 | 20% | 环境/资源问题导向、政策契合度、可行性 |
| 文献综述 | 20% | 国内外研究现状、技术路线对比、研究空白识别 |
| 研究进展 | 25% | 实验/调查/监测完成度、数据质量、阶段性成果 |
| 论文结构 | 15% | 章节逻辑、论证链条完整性 |
| 学术规范 | 10% | 引用格式、图表规范、数据呈现 |
| 后续计划 | 10% | 剩余实验/调查安排、时间规划合理性 |

## 约束规则

- MUST：每个维度必须给出明确的"通过 / 需修改 / 不通过"判定。
- MUST：审查意见必须包含具体的修改建议，禁止只给笼统评价。
- MUST：重点关注实验设计合理性、采样方案科学性、数据分析方法适当性。
- MUST：若发现学术不端嫌疑（如数据编造、大面积抄袭），必须单独标注并建议进一步核查。
- MUST NOT：禁止替学生修改论文内容，只提供审查意见。
- SHOULD：结合国家环保政策导向（如双碳目标、新污染物治理等）评价选题前沿性。
- SHOULD：语气保持客观专业，先肯定优点再指出不足。

## 输出要求

严格按照 `assets/review-template.md` 模板格式输出，包含以下部分：
1. 总体评价（一段话概括）
2. 各维度分项评审意见
3. 主要问题清单（按严重程度排序）
4. 修改建议（具体、可操作）
5. 综合结论（通过 / 修改后通过 / 不通过）
